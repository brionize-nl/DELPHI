# Ollama Modelfiles

Custom modellen voor ollama.brionize.nl.

## Installatie op VPS

```bash
cd /pad/naar/Brionicle/ollama/modelfiles
ollama create coder -f Modelfile.coder
ollama create sysadmin -f Modelfile.sysadmin
ollama create schrijver -f Modelfile.schrijver
```

## Beschikbare modellen

- **coder** — Developer assistent (lage temperatuur, precieze code)
- **sysadmin** — Linux/DevOps hulp
- **schrijver** — Creatief schrijven in het Nederlands
